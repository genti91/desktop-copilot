Sincronización con GitHub

Cada push a main que toque firmware/ dispara una compilación en GitHub Actions que publica un release. Este backend lo revisa periódicamente y lo deja listo para el ESP32, sin que tengas que subir nada a mano.

Publicar a mano

Alternativa por si querés probar un binario sin pasar por GitHub. Compilá con pio run -e xiao_esp32s3 y subí firmware/.pio/build/xiao_esp32s3/firmware.bin. El build tiene que ser mayor al instalado en el dispositivo.

El recorrido completo

  1. Editás el firmware y hacés push a main.
  2. GitHub Actions compila y publica un release. El número de build sale de la cantidad de commits, así que sube solo.
  3. Este backend detecta el release, verifica el SHA-256 y lo deja publicado.
  4. El ESP32 consulta el manifest al arrancar y cada 15 minutos en reposo.
  5. Si el build remoto es mayor, descarga con progreso en pantalla, revalida el SHA-256 y reinicia. Si el hash no coincide, aborta y sigue con el firmware actual.
